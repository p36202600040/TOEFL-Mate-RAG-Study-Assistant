# Folder Data Dokumen Sumber

Letakkan file PDF buku resmi TOEFL di folder ini, misalnya:
`eBook_TOEFL_Official_Guide_4e.pdf`

Setelah PDF diletakkan di folder ini, jalankan perintah ingestion untuk membangun indeks ChromaDB:
```powershell
python scripts/ingest_pdf.py
```
*(Catatan: File PDF buku berhak cipta tidak disertakan di repositori/ZIP demi mematuhi ketentuan hak cipta ETS).*
